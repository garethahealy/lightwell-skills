# Lightwell

Cursor plugin (shareable skills) for Red Hat Lightwell / Trusted Packages:
upgrade Maven directs and transitives, verify attestations, and comment OSV
on Renovate PRs.

This directory is the plugin package (`plugin.json` under `.cursor-plugin/`).
Install it; do not treat this tree as a Maven app.

Docs, marketplace manifest, and local symlink instructions:
https://github.com/garethahealy/lightwell-skills
